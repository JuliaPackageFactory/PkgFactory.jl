Publish to Julia's General registry

PkgFactory creates the repository. When your public package is ready for release, complete these steps separately to register it in General.

  1. Registrator GitHub App

    Install or configure Registrator GitHub App for the repository owner and grant it access to the new repository. The public Registrator service does not support private repositories.

  2. General registration

    Review the General registration guidelines, set the release version in Project.toml, and commit your changes. On GitHub, open the commit you want to register and comment @JuliaRegistrator register.

    Follow the registration pull request opened by Registrator in General and address any feedback or failed checks. Registration is complete when that pull request is merged.
